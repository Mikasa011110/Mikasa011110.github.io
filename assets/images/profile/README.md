# Profile photo

1. Put your real portrait here, e.g. `profile.jpg`.
2. Open `_data/profile.yml`.
3. Change:

```yml
photo: "/assets/images/profile/profile-placeholder.svg"
```

to:

```yml
photo: "/assets/images/profile/profile.jpg"
```

A portrait around 1200×1500 px works well. Use a simple background and keep your face near the upper-middle of the frame.
